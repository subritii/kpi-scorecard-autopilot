      Built so accountants can trust it

      • The math is code, never AIEvery KPI is calculated by tested code with exact decimals.
      • AI says what moved, never whyEvery sentence it writes is checked against the books. Reasons come from owners.
      • Approved first, sent onceNothing reaches a client without the Controller, and never twice.
      • Each client's books stay separateThe database itself keeps clients apart, and the AI runs locally, so client data stays in-house.

      Checked against an answer key

      Measured on synthetic data with planted problems whose answers are known. It shows the system does what it was designed to do, not how it would score on messy real books.

      Why I built this

      Fractional CFO firms run the same weekly KPI review for every client, and much of it is copy, paste and chase. I wanted to automate that routine with tools these firms already use, while keeping accountants in control of every judgment call.

      I built it with Claude Code assistance. I designed the workflow, the safeguards, the tests and the evaluation, and checked the QuickBooks pull against QuickBooks' own report.
