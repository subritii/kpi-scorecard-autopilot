Why I built it

Fractional CFO firms run the same weekly KPI review for every client, and much of it is copy, paste and chase.

I wanted to automate that routine with the tools these firms already use (QuickBooks, ClickUp, n8n) while keeping accountants in control.

Built with Claude Code assistance; I designed the workflow, the tests and the evaluation.
